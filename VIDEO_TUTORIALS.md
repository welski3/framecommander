# FrameCommander — Video Tutorials

Welcome to the FrameCommander video guide. These tutorials help you deploy the WebUI, connect RunningHub, and start generating videos with the published ComfyUI-powered workflow.

## Complete setup tutorial

**[Watch the FrameCommander setup tutorial on YouTube](https://www.youtube.com/watch?v=DS-XPUw7zSQ)**

This approximately 15-minute walkthrough demonstrates the setup and use of FrameCommander, including:

- Deploying your own FrameCommander WebUI using Netlify Drop.
- Finding the **Consumer-Membership API Key** in RunningHub (profile picture → **Console** → **API Keys** → **Consumer-Membership API Key** → **Reset Text**).
- Adding your RunningHub API key to FrameCommander.
- Optionally configuring an LLM API key, such as Gemini, for supported features.
- Using the published RunningHub workflow from the WebUI. You **do not need to import a workflow or enter a workflow ID** for the standard setup.

> **Security note:** Keep API keys private. Resetting a key can invalidate an earlier one. Never commit API keys to GitHub or share them in videos.
